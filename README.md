# Netflix Movies & TV Shows Analysis

## Overview
Analyzed Netflix dataset using Python and visualization libraries.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Features
- Data Cleaning
- EDA
- Genre Analysis
- Country Analysis
- Visualizations

## Key Insights
- Movies dominate Netflix
- USA produces most content
- TV-MA is the most common rating
